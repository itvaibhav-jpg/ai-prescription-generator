# 🏥 MediScript AI - Enterprise Prescription Generator

An advanced, enterprise-grade AI-powered medical prescription generator that uses **Google Gemini AI** to create professional, detailed medical prescriptions based on patient symptoms and medical history.

## ✨ Features

### 🤖 Real AI Integration
- **Google Gemini 2.0 Flash** - Latest AI model for medical prescription generation
- Real-time AI analysis of patient symptoms
- Intelligent medication recommendations
- Comprehensive treatment plans

### 💼 Enterprise-Grade Features
- **Professional UI/UX** - Modern, responsive design
- **Complete Patient Management** - Track age, gender, weight, allergies
- **Doctor Information** - Specialization and credentials
- **Detailed Prescriptions** - Diagnosis, medications, dosage, instructions
- **Print & Download** - PDF-ready prescription output
- **Mobile Responsive** - Works on all devices

### 🔒 Safety Features
- Allergy checking and warnings
- Current medication tracking
- Side effect warnings
- Professional disclaimers
- Medical accuracy validation

## 📋 How to Use

1. **Enter Patient Information**
   - Patient name, age, gender, weight
   - Known allergies
   - Current medications

2. **Enter Doctor Information**
   - Doctor name
   - Specialization

3. **Describe Symptoms**
   - Detailed symptom description
   - Medical history
   - Diagnosis information

4. **Generate Prescription**
   - Click "Generate AI Prescription"
   - AI analyzes the information
   - Comprehensive prescription generated

5. **Download/Print**
   - Print prescription
   - Download as PDF
   - Share with patients
